# Palette.ai - Assistente Centralizador de Assets

**Contexto e Dor Real:** Designers de interface sofrem com um processo exaustivo e fragmentado, perdendo tempo pulando entre vários sites para estruturar cores, fontes e imagens para um novo projeto

**Solução:** Uma aplicação web que recebe as diretrizes do projeto e atua como uma assistente de curadoria, centralizando paletas, tipografias combinadas e ícones em um só lugar. A ferramenta aplica o conceito Human-in-the-loop, não desenhando a tela final para evitar a homogeneização gerada por IAs.

**Fora do MVP 1 (Lista Proibida):** Exportação direta para softwares de edição, geração de protótipos de alta fidelidade e manipulação de imagens

**RF-CORE:** RF-01 (Receber inputs de público e tema) | RF-02 (Gerar sugestões de paletas) | RF-03 (Sugerir combinações tipográficas) | RF-04 (Exibir ícones e referências)
